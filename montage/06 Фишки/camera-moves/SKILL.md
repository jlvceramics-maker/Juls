# 24 приема камеры и монтажа для анимации кодом

Этот документ для ИИ-агента, который делает анимацию, мультфильм или ролик кодом. Он превращает операторскую и монтажную грамматику в готовые паттерны. По каждому приему здесь описано, что меняется в кадре, что это говорит зрителю, с каких чисел начинать, как написать в Three.js или Canvas 2D и где обычно ломается.

Все числа проверены на реальных роликах. Это стартовые значения, не догма. Меняй их, если сцена просит.

## Как пользоваться

1. **Выбери прием по смыслу, а не по эффектности.** У каждого движения должно быть законченное «камера движется, потому что...». Если продолжения нет, движение лишнее. Таблицы «24 приема» и «Что подходит под задачу» подскажут выбор.
2. **Построй сцену, в которой прием виден.** Перевод фокуса без двух планов на разной глубине не читается. Долли-зум без далекого фона тоже. Проводка без переднего плана выглядит как сдвиг картинки.
3. **Возьми параметры и код** из раздела приема. Скопируй модуль-помощник из раздела «Модуль-помощник» в проект.
4. **Проверь кадрами до полного рендера.** Сделай стоп-кадры в ключевых точках каждого приема (начало, середина движения, вершина, момент склейки) и лист кадров раз в 0,5 с по всему ролику. Большинство ловушек видно только на кадре.

## 24 приема

Русское название нужно человеку, английский термин подходит для имен функций и для промптов видеомоделей.

## Постановка сцены по умолчанию

Все числа ниже даны для такой постановки. Если у тебя другой масштаб, пересчитай пропорционально.

- Единицы в метрах, ось `y` вверх. Герой ростом около 1,75 м стоит в начале координат лицом к `+z`.
- Камера `THREE.PerspectiveCamera` с `rotation.order = 'YXZ'` (рыскание, потом тангаж, потом крен). По умолчанию стоит в `(0, 1.5, 10)` и смотрит вдоль `-z`. Горизонт идет по середине кадра, ноги героя примерно на трех четвертях высоты.
- Фокусное переводится в вертикальный угол обзора формулой `fov = 2·atan(6.9 / mm)`. 24 мм дают 32°, это кадр, близкий к кино. Так показания «24 мм» и «87 мм» имеют смысл для зрителя.
- Сцене нужны слои по глубине. Передний план (столб, камень, ветка) в 3-5 м от камеры, средний (деревья) на 30-45 м, дальний (дома) на 55-75 м, горизонт (горы) на 300-450 м. Без слоев движение камеры выглядит как сдвиг плоской картинки.
- Плоские материалы без света (`MeshBasicMaterial`) дают чистый иллюстративный вид. Глубину тогда создают туман (`Fog`, примерно 45-230 м) и слои. Дальние горы рисуй без тумана (`fog: false`), иначе они растворятся.
- Все объекты, которые включает хотя бы один кадр, выключаются в общем `reset()`, который вызывается перед каждым проходом сцены. Туда же входит возврат камеры, цвета неба и тумана.

Для Canvas 2D без 3D тот же прием делается параллаксом. Каждому слою задай глубину `z`, экранный сдвиг `dx = camX / z` и масштаб `s = f / (z − camZ)`. В разделе каждого приема сказано, что именно двигать.

## Время и ритм

- **Петля для демонстрации одного приема (4,7 с).** Пауза 0-0,8 с, движение 0,8-2,8 с, пауза до 4,2 с, растворение в начальный кадр за последние 0,5 с. Если поверх кадра есть цифры (фокусное, скорость), при растворении сразу показывай значения из начала петли, иначе цифры двоятся.
- **Ролик-история.** Один прием на кадр, кадры по 1-2,5 с в динамичном ролике. Первое движение начинается через 0,1-0,3 с от начала кадра, иначе выглядит как рывок. После посадки важного кадр стоит хотя бы секунду.
- **Склейки.** Основная склейка жесткая. Эффектные переходы (переброска, наплыв, шторка) только в 2-3 ключевых местах. Исключение ролик, который учит самим переходам.
- **Кривые.** Движение камеры ease in-out cubic. Удары (резкий зум, переброска) ease out. Зум, наезд и кран с большим диапазоном интерполируй по логарифму величины, иначе движение кажется тормозящим к концу.
- **Детерминизм.** Кадр должен быть чистой функцией времени `renderFrame(t)`. Случайность только из генератора с сидом, тряска только суммой синусов. Никаких `Math.random()` и `performance.now()` внутри кадра, иначе превью и рендер разойдутся.
- **Сюжетное время.** Слоумо, спидрамп и стоп-кадр меняют не камеру, а время мира. В сцене есть реальное время кадра `u` и сюжетное `s = story(u)`. Герой, частицы, машины, солнце и звуки шагов живут в `s`. Тогда один график скорости дает все три приема без отдельного кода для каждого объекта.

## Модуль-помощник

Скопируй в проект как `camera-kit.js`. Модуль без зависимостей, Three.js передается параметром. Все функции дальше в документе ссылаются на него.

```js
// camera-kit.js. Операторская грамматика для анимации кодом (Three.js + Canvas 2D).
// Камера: THREE.PerspectiveCamera с rotation.order 'YXZ'. Метры и градусы.
// Герой в начале координат лицом к +z, камера по умолчанию в (0, 1.5, 10) смотрит вдоль -z.

// ---------- математика ----------
export const TAU = Math.PI * 2;
export const clamp01 = (x) => Math.max(0, Math.min(1, x));
export const lerp = (a, b, k) => a + (b - a) * k;
export const ease = (x) => (x < 0.5 ? 4 * x * x * x : 1 - Math.pow(-2 * x + 2, 3) / 2); // in-out cubic
export const easeOut = (x) => 1 - Math.pow(1 - clamp01(x), 3);
export const smooth = (a, b, x) => { const k = clamp01((x - a) / (b - a)); return k * k * (3 - 2 * k); };
export const seg = (t, a, b, fn = ease) => fn(clamp01((t - a) / (b - a)));          // прогресс 0..1 на отрезке
export const logLerp = (a, b, k) => Math.exp(lerp(Math.log(a), Math.log(b), k));    // зум, кран, большой наезд
export const rad = (d) => (d * Math.PI) / 180;
export const deg = (r) => (r * 180) / Math.PI;
export const fovOf = (mm, k = 6.9) => deg(2 * Math.atan(k / mm));                    // 24 мм → 32°
export const mmOf = (fov, k = 6.9) => k / Math.tan(rad(fov) / 2);
export const hfovOf = (vfov, aspect) => deg(2 * Math.atan(aspect * Math.tan(rad(vfov) / 2)));
export function rng(seed) { // mulberry32
  let a = seed >>> 0;
  return () => { a = (a + 0x6d2b79f5) >>> 0; let t = a; t = Math.imul(t ^ (t >>> 15), t | 1); t ^= t + Math.imul(t ^ (t >>> 7), t | 61); return ((t ^ (t >>> 14)) >>> 0) / 4294967296; };
}
export const num = (v, d = 1) => v.toFixed(d).replace('.', ',');                    // «1,7» для показаний
export const signed = (v) => (v > 0 ? '+' : v < 0 ? '−' : '') + Math.abs(v);

// ---------- петля демо ----------
export function loopPhase(t, { period = 4.7, hold = 0.8, move = 2.0, fade = 0.5 } = {}) {
  const lt = ((t % period) + period) % period;
  return { lt, k: seg(lt, hold, hold + move), fadeK: fade ? smooth(period - fade, period, lt) : 0 };
}

// ---------- риги камеры: ставят камеру по прогрессу k или времени t и возвращают показание ----------
const setPos = (cam, p) => cam.position.set(p[0], p[1], p[2]);
const look = (cam, p) => cam.lookAt(p[0], p[1], p[2]);
export const rigs = {
  pan(cam, k, { from = -18, to = 18, pos = [0, 1.5, 10] } = {}) {             // 01
    const a = lerp(from, to, k); setPos(cam, pos); cam.rotation.set(0, rad(-a), 0, 'YXZ'); return `${signed(Math.round(a))}°`;
  },
  tilt(cam, k, { from = -3, to = 21, pos = [0, 1.2, 7.5] } = {}) {            // 02
    const a = lerp(from, to, k); setPos(cam, pos); cam.rotation.set(rad(a), 0, 0, 'YXZ'); return `${signed(Math.round(a))}°`;
  },
  dolly(cam, k, { from = 10, to = 2.6, height = 1.45, mm = 24 } = {}) {        // 03
    setPos(cam, [0, height, lerp(from, to, k)]); cam.rotation.set(0, 0, 0, 'YXZ'); cam.fov = fovOf(mm); return `${mm} мм`;
  },
  zoom(cam, k, { from = 24, to = 87, pos = [0, 1.45, 10] } = {}) {             // 04
    const mm = logLerp(from, to, k); setPos(cam, pos); cam.rotation.set(0, 0, 0, 'YXZ'); cam.fov = fovOf(mm); return `${Math.round(mm)} мм`;
  },
  tracking(cam, x, { dist = 7.6, height = 1.5, lead = 0, speed = 1.7 } = {}) { // 05, x героя задает сцена
    setPos(cam, [x + lead, height, dist]); cam.rotation.set(0, 0, 0, 'YXZ'); return `→ ${num(speed)} м/с`;
  },
  orbit(cam, k, { from = -54, to = 54, radius = 6.2, height = 1.75, target = [0, 1.05, 0] } = {}) { // 06
    const a = lerp(from, to, k);
    setPos(cam, [target[0] + Math.sin(rad(a)) * radius, height, target[2] + Math.cos(rad(a)) * radius]); look(cam, target);
    return `${signed(Math.round(a))}°`;
  },
  crane(cam, k, { from = 1.4, to = 9, dist = 8, target = [0, 0.9, 0] } = {}) { // 07
    const h = logLerp(from, to, k); setPos(cam, [target[0], h, target[2] + dist]); look(cam, target); return `↑ ${num(h)} м`;
  },
  dollyZoom(cam, k, { fromMm = 10, toMm = 24, d0 = 4.2, height = 1.5 } = {}) { // 08, d = d0 · f / f0
    const mm = lerp(fromMm, toMm, k);
    cam.fov = fovOf(mm); setPos(cam, [0, height, d0 * mm / fromMm]); cam.rotation.set(0, 0, 0, 'YXZ'); return `${Math.round(mm)} мм`;
  },
  handheld(cam, t, { loop = 4.7, pos = [0, 1.5, 10], amp = 1 } = {}) {         // 10, кратные частоты дают петлю без шва
    const w = TAU / loop, n = (list) => list.reduce((s, [a, m, p]) => s + a * Math.sin(w * m * t + p), 0) * amp;
    cam.position.set(pos[0] + n([[0.03, 3, 0.2], [0.015, 7, 1.1]]), pos[1] + n([[0.02, 5, 2.1], [0.01, 11, 0.4]]), pos[2]);
    cam.rotation.set(rad(n([[0.45, 4, 0.7], [0.2, 9, 2.2]])), rad(n([[0.55, 3, 1.4], [0.25, 8, 0.1]])), rad(n([[0.6, 2, 0.3], [0.25, 7, 1.9]])), 'YXZ');
    return 'С РУК';
  },
  fpv(cam, t, { speed = 13.9, start = [0, 2.2, 34], weave = 1.4, freq = 1.35, roll = 0.34, pitch = -4 } = {}) { // 11
    cam.position.set(start[0] + weave * Math.sin(t * freq), start[1] + 0.5 * Math.sin(t * 0.9), start[2] - speed * t);
    cam.rotation.set(rad(pitch + 3 * Math.sin(t * 0.9 + 1)), -0.16 * Math.cos(t * freq), roll * Math.sin(t * freq + 0.5), 'YXZ');
    return `${Math.round(speed * 3.6)} км/ч`;
  },
  dutch(cam, k, { to = 21, pos = [0, 1.5, 10] } = {}) {                         // 12
    const a = lerp(0, to, k); setPos(cam, pos); cam.rotation.set(0, 0, rad(a), 'YXZ'); return `∠ ${Math.round(a)}°`;
  },
};

// ---------- сюжетное время: слоумо, спидрамп, стоп-кадр ----------
// segments по порядку: { until, rate } держит скорость, { until, to } плавно меняет ее к to, последний без until
export function piecewiseRate(segments) {
  return (u) => {
    let prevEnd = 0, prevRate = segments[0].rate ?? 1;
    for (const s of segments) {
      const end = s.until ?? Infinity;
      if (u < end) return s.to != null ? lerp(prevRate, s.to, smooth(prevEnd, end, u)) : s.rate;
      prevRate = s.to ?? s.rate; prevEnd = end;
    }
    return prevRate;
  };
}
// story(u) сюжетное время, real(s) реальное время, когда сюжет дошел до s
export function makeStoryTime(rate, { until = 30, dt = 0.002 } = {}) {
  const n = Math.ceil(until / dt), acc = new Float64Array(n + 1);
  for (let i = 1; i <= n; i++) acc[i] = acc[i - 1] + rate((i - 0.5) * dt) * dt;
  const story = (u) => { const f = Math.max(0, Math.min(n, u / dt)), i = Math.floor(f); return acc[i] + (acc[Math.min(n, i + 1)] - acc[i]) * (f - i); };
  const real = (s) => { let lo = 0, hi = n; while (lo < hi) { const m = (lo + hi) >> 1; if (acc[m] < s) lo = m + 1; else hi = m; } return lo * dt; };
  return { story, rate, real };
}

// ---------- переходы ----------
export const jumpIndex = (t, count, step) => Math.min(count - 1, Math.floor(t / step));          // 17
export function whip(u, { start = 0.2, dur = 0.6, angle = 40, blur = 60 } = {}) {                // 19
  const half = dur / 2;
  if (u < start) return { side: 'from', yaw: 0, hblur: 0 };
  if (u < start + half) { const k = Math.pow((u - start) / half, 2); return { side: 'from', yaw: -angle * k, hblur: blur * k }; }
  if (u < start + dur) { const k = 1 - Math.pow(1 - (u - start - half) / half, 2); return { side: 'to', yaw: angle * (1 - k), hblur: blur * (1 - k) }; }
  return { side: 'to', yaw: 0, hblur: 0 };
}
export const dissolve = (u, { start = 1.0, dur = 1.2 } = {}) => seg(u, start, start + dur);      // 20
export const wipeX = (u, width, { start = 1.0, dur = 1.1 } = {}) => seg(u, start, start + dur) * width; // 21
export const jCut = (cut, lead = 0.45) => ({ audioStart: cut - lead });                          // 23
export const lCut = (cut, tail = 0.4) => ({ audioEnd: cut + tail });                             // 24

// ---------- компоновщик проходов сцены ----------
// renderer: { preserveDrawingBuffer: true, alpha: true }, pixelRatio 1, холст размером с ctx.canvas.
// shot(setup, o): reset() → setup(camera, scene) → рендер → размытие или смаз → прозрачность и обрезка → в ctx.
//   o.alpha (наплыв), o.blur px (перевод фокуса), o.hblur px (переброска), o.transparent (слой без фона),
//   o.rect {x,y,w,h} (часть холста), o.clip {x,y,w,h} (шторка).
// Возвращает project(x, y, z) → {x, y} в пикселях холста для 2D-оверлеев.
export function makeCompositor({ THREE, renderer, scene, camera, ctx, reset = () => {} }) {
  const W = ctx.canvas.width, H = ctx.canvas.height, gl = renderer.domElement;
  const tmp = document.createElement('canvas'); tmp.width = W; tmp.height = H;
  renderer.setScissorTest(true);
  function shot(setup, o = {}) {
    const r = o.rect || { x: 0, y: 0, w: W, h: H };
    reset();
    camera.aspect = r.w / r.h;
    if (setup) setup(camera, scene);
    camera.updateProjectionMatrix(); camera.updateMatrixWorld();
    const glY = H - r.y - r.h;
    renderer.setViewport(r.x, glY, r.w, r.h); renderer.setScissor(r.x, glY, r.w, r.h);
    const bg = scene.background;
    if (o.transparent) { scene.background = null; renderer.setClearColor(0x000000, 0); }
    else renderer.setClearColor(bg && bg.isColor ? bg : 0xffffff, 1);
    renderer.clear(); renderer.render(scene, camera);
    scene.background = bg;
    const t = tmp.getContext('2d');
    t.setTransform(1, 0, 0, 1, 0, 0); t.globalAlpha = 1; t.filter = 'none'; t.clearRect(0, 0, W, H);
    if (o.hblur > 0.5) {
      const n = 16;
      for (let i = 0; i < n; i++) { t.globalAlpha = 1 / (i + 1); t.drawImage(gl, r.x, r.y, r.w, r.h, r.x + (i / (n - 1) - 0.5) * o.hblur, r.y, r.w, r.h); }
      t.globalAlpha = 1;
    } else {
      if (o.blur) t.filter = `blur(${o.blur.toFixed(2)}px)`;
      t.drawImage(gl, r.x, r.y, r.w, r.h, r.x, r.y, r.w, r.h); t.filter = 'none';
    }
    const c = o.clip || r;
    ctx.save(); ctx.setTransform(1, 0, 0, 1, 0, 0);
    ctx.beginPath(); ctx.rect(c.x, c.y, c.w, c.h); ctx.clip();
    ctx.globalAlpha = o.alpha ?? 1; ctx.drawImage(tmp, 0, 0);
    ctx.restore();
    const vm = camera.matrixWorldInverse.clone(), pm = camera.projectionMatrix.clone();
    return (x, y, z) => { const v = new THREE.Vector3(x, y, z).applyMatrix4(vm).applyMatrix4(pm); return { x: r.x + (v.x + 1) / 2 * r.w, y: r.y + (1 - v.y) / 2 * r.h }; };
  }
  return { shot, W, H };
}

// растворение петли в начало: draw(lt, ctx) рисует кадр в момент lt и возвращает его показания
export function makeLoopFader(W, H) {
  const mk = () => { const c = document.createElement('canvas'); c.width = W; c.height = H; return c; };
  const a = mk(), b = mk();
  return (t, { period = 4.7, fade = 0.5 }, draw, out) => {
    const lt = ((t % period) + period) % period;
    if (!fade || lt < period - fade) return draw(lt, out);
    const resA = draw(lt, a.getContext('2d')), resB = draw(0, b.getContext('2d'));
    const k = smooth(period - fade, period, lt);
    out.save(); out.setTransform(1, 0, 0, 1, 0, 0); out.globalAlpha = 1; out.drawImage(a, 0, 0); out.globalAlpha = k; out.drawImage(b, 0, 0); out.restore();
    return k > 0.35 ? resB : resA; // цифры сразу из начала петли
  };
}
```

## Движение камеры (01-08)

Прогресс `k` в примерах берется из `seg(t, 0.8, 2.8)` или `loopPhase(t).k`.

### 01 Панорама · pan

- **Суть.** Камера стоит на месте и поворачивается по горизонтали. Мир едет по кадру целиком, без параллакса.
- **Когда.** Осмотреть место, перевести взгляд с одного на другое, показать, что герой один или что рядом кто-то есть.
- **По умолчанию.** От −18° до +18° за 2 с, ease in-out. Показание «−18°».
- **Код.** `rigs.pan(cam, k)`. Это `cam.rotation.y = rad(-a)`, положительный угол поворачивает вправо.
- **Canvas 2D.** Все слои сдвигаются на одинаковое `dx`. Если слои едут с разной скоростью, это уже проезд, а не панорама.
- **Ловушки.** Герой должен остаться в кадре. Половина горизонтального угла равна `hfovOf(32, aspect) / 2`, для 16:9 это около 27°. Расставь объекты по дуге 180° за героем, иначе при повороте открывается пустой край мира.

### 02 Вертикальная панорама · tilt

- **Суть.** Камера стоит и поворачивается вверх или вниз. Вертикали сходятся, это нормально.
- **Когда.** Раскрыть высоту (небоскреб, гора, великан), перейти от героя к небу, финальный взгляд вверх.
- **По умолчанию.** Камера ниже и ближе, `(0, 1.2, 7.5)`. Угол от −3° до +21°. За героем на 20-25 м стоит высокий объект (дом на 17 м с антенной и мигающей точкой на верхушке), рядом с вершиной солнце.
- **Код.** `rigs.tilt(cam, k)`. Это `cam.rotation.x = rad(a)`, положительный угол смотрит вверх.
- **Canvas 2D.** Все слои сдвигаются на одинаковое `dy`.
- **Ловушки.** Если над героем пустое небо, прием не читается. В конце движения герой уходит под нижний край, так и задумано.

### 03 Наезд · dolly in

- **Суть.** Камера едет к герою, фокусное не меняется. Передний план быстро проезжает мимо и уходит из кадра, фон остается маленьким. Этим наезд и отличается от зума.
- **Когда.** Сблизиться с героем, нарастить напряжение, войти в его мир.
- **По умолчанию.** `z` от 10 до 2,6 м, 24 мм, высота 1,45 м. Передний план из тонкого столба (0,11 × 1,7 м) в `(-2.4, 0, 4.8)` и камня в `(2.1, 0, 6.6)`. Показание остается «24 мм», это подсказка, что меняется не оптика.
- **Код.** `rigs.dolly(cam, k)`. Большой диапазон двигай через `logLerp`.
- **Canvas 2D.** Масштаб слоя `s = f / (z − camZ)`. Ближние слои растут быстрее дальних, ближайшие разлетаются за края.
- **Ловушки.** Без переднего плана наезд неотличим от зума. Камера не должна проезжать сквозь героя, останавливайся на 2,5-3 м.

### 04 Зум · zoom in

- **Суть.** Камера стоит, растет фокусное. Весь кадр увеличивается одинаково, перспектива сплющивается, фон становится крупным. Передний план уходит из кадра обрезкой, а не пролетом.
- **Когда.** Выхватить деталь, сделать акцент, резкий комедийный зум в лицо.
- **По умолчанию.** Плавный зум 24 → 87 мм за 2 с по логарифму. Резкий зум 24 → 120-135 мм за 0,3-0,5 с через `easeOut`, взгляд чуть поднимается к лицу.
- **Код.** `rigs.zoom(cam, k, { from: 24, to: 87 })`. После смены `fov` нужен `updateProjectionMatrix()`, компоновщик делает его сам.
- **Canvas 2D.** Один общий масштаб всех слоев от центра кадра.
- **Ловушки.** Линейный твин фокусного выглядит как разгон. Если показываешь наезд и зум рядом, доведи героя до одинакового размера, тогда разница фона очевидна.

### 05 Проводка · tracking shot

- **Суть.** Камера едет вбок вместе с героем на той же скорости. Герой стоит в кадре, мир течет. Ближний план мелькает быстро, дальний ползет.
- **Когда.** Путь, движение, погоня, мы идем рядом.
- **По умолчанию.** Шаг 1,7 м/с, бег 6 м/с. Камера в `(x + lead, 1.3-1.5, 7.4-7.6)`. Столбы между камерой и героем на `z = 4.4`, шаг 3,4 м, высота 2,3 м. Герой повернут боком (`rotation.y = π/2`), цикл шага `walk = s·2π·1.7`, размах ног 0,5 для шага и 0,8 для бега, подскок тела 4-6 см.
- **Код.** `rigs.tracking(cam, heroX, { lead: 0.8, speed: 6 })`. `heroX` считай из сюжетного времени, тогда спидрамп и стоп-кадр заработают сами.
- **Canvas 2D.** Слои едут со скоростью `v / z`, герой стоит.
- **Ловушки.** Столб переднего плана закрывает героя ровно в ключевой момент. Проекция героя на плоскость столбов лежит в `xp = camX + (heroX − camX)·(camZ − postZ)/(camZ − heroZ)`. Сдвинь группу столбов так, чтобы в ключевой момент ближайший был в половине шага от `xp`. Сбоку руки сливаются с телом, поэтому жесты руками в проводке не читаются.

### 06 Облет · orbit (arc shot)

- **Суть.** Камера идет по дуге вокруг героя и все время смотрит на него. Фон вращается за героем.
- **Когда.** Триумф, раскрытие героя, он в центре мира, финал.
- **По умолчанию.** Радиус 5,6-6,2 м, высота камеры 1,6-1,75 м, цель `(0, 1.05-1.15, 0)`. Дуга ±54° для демонстрации или 80° в одну сторону для истории. Пунктирное кольцо на земле радиусом около 1 м (`LineDashedMaterial` и `computeLineDistances()`) помогает прочитать дугу. Глаза у героя показывают, куда он смотрит.
- **Код.** `rigs.orbit(cam, k, { from: -54, to: 54 })`.
- **Canvas 2D.** Честный облет в 2D не получается. Можно сдвигать слои в противоположные стороны относительно героя (ближние в одну, дальние в другую) и сжимать героя по ширине на `cos(a)`.
- **Ловушки.** Сбоку плоский персонаж превращается в палку. Держи углы до 50° или выбирай дугу, где поза читается спереди. Предмет за героем (машина, дерево) в какой-то точке дуги встанет ровно за ним и слипнется в один силуэт. Проверь линию «камера, герой, предмет» по всей дуге и выбери дугу, на которой линия не проходит через предмет.

### 07 Кран вверх · crane up

- **Суть.** Камера поднимается и смотрит вниз на героя. Он становится маленьким, площадь вокруг большой.
- **Когда.** Одиночество, масштаб, мир огромен, финальный отход.
- **По умолчанию.** Высота от 1,4 до 9-16 м по логарифму, дистанция по горизонтали 8-9 м, цель `(0, 0.9, 0)`. Показание «↑ 9,0 м».
- **Код.** `rigs.crane(cam, k, { from: 1.5, to: 16, dist: 9 })`.
- **Canvas 2D.** Горизонт уходит вверх за кадр, герой уменьшается, пол заполняет кадр сеткой в перспективе.
- **Ловушки.** На большой высоте горизонта не видно, кадр становится полом с сеткой. Если горизонт нужен, увеличь дистанцию или целься за героя.

### 08 Долли-зум · dolly zoom (vertigo)

- **Суть.** Камера отъезжает, а зум компенсирует. Герой остается того же размера, фон растет и надвигается. Обратный вариант (наезд с отзумом) отбрасывает фон вдаль.
- **Когда.** Озарение, шок, паника. Сильный хук в начале ролика.
- **По умолчанию.** Плавно 10 → 24 мм за 2 с, резко 16 → 52 мм за 1,3 с. Дистанция `d = d0 · f / f0`, где `d0` 2,9-4,2 м. Высота камеры постоянная, взгляд горизонтальный. Две пунктирные линии на уровне макушки и ног доказывают зрителю, что размер героя не меняется.
- **Код.** `rigs.dollyZoom(cam, k, { fromMm: 16, toMm: 52, d0: 2.9 })`.
- **Почему формула верна.** Доля кадра под героем равна `(H / d) / tan(fov/2)`. При `tan(fov/2) = 6.9 / f` это `H · f / (6.9 · d)`, и она постоянна при `d ∝ f`.
- **Ловушки.** Нужен далекий фон (дома на 50 м и дальше), иначе эффект слабый. Не добавляй тряску, глаз должен видеть ровное движение фона. Поза паники лучше читается с руками вверх, чем с руками в стороны.

## Съемка и время (09-16)

Первые четыре приема меняют то, как снимает камера. Последние четыре меняют время мира, и камера в них почти ни при чем. Для них используй `makeStoryTime` и считай все движения сцены от `story(u)`.

### 09 Перевод фокуса · rack focus

- **Суть.** В одном кадре резкость переходит с ближнего объекта на дальний или обратно. Ничего не двигается, меняется только то, что резко.
- **Когда.** Переключить внимание, связать два объекта, «он заметил». Можно открыть второй объект, который появляется за героем.
- **По умолчанию.** Камера низко, `(0, 0.9-1.25, 10)`. Ближний объект в 2-2,5 м (крупный и цветной, например цветок в нижнем углу), дальний в 9-11 м. Перевод за 0,6 с. Показание «◎ 2 м» → «◎ 9 м». Рамка фокуса из четырех уголков переезжает с ближнего объекта на дальний.
- **Код.** Два прохода компоновщика. Размытие в пикселях указано для кадра шириной 1920, для маленького кадра уменьшай пропорционально.
  ```js
  const k = seg(u, 0.35, 0.95);
  C.shot((cam) => { setup(cam); near.visible = false; }, { blur: lerp(9, 0, k) });              // мир
  const p = C.shot((cam) => { setup(cam); showOnly(near); }, { transparent: true, blur: lerp(0, 14, k) }); // ближний слой
  ```
- **Альтернатива.** Постобработка с глубиной резкости (например `BokehPass` в Three.js) честнее, но медленнее и капризнее на простых сценах. Двумя слоями проще и предсказуемее.
- **Ловушки.** Нужны два плана на разной глубине. Маленький размытый ближний объект просто пропадает, поэтому он должен быть крупным. Дальний объект в размытии сливается с фоном, помогает акцентный цвет.

### 10 Ручная камера · handheld

- **Суть.** Мелкая органичная тряска позиции и поворота, как у оператора без стабилизатора.
- **Когда.** Документальность, тревога, присутствие. Под шок идет сильная короткая тряска.
- **По умолчанию.** Позиция ±2-3 см, повороты ±0,5°. Сумма синусов с частотами, кратными частоте петли.
- **Код.** `rigs.handheld(cam, t, { loop: 4.7 })`. Для удара добавь шум от сида `rng(frame)` с амплитудой 3-5 см только на 1-1,5 с.
- **Ловушки.** Новый случайный сдвиг на каждый кадр выглядит как цифровой дребезг, а не как руки. Нужны низкие частоты. Кратные частоты делают петлю бесшовной, тогда растворение в конце петли не нужно.

### 11 FPV-дрон · FPV drone shot

- **Суть.** Быстрый полет вперед, низко над землей, змейкой и с креном в поворот. Предметы проносятся близко.
- **Когда.** Азарт, погоня, полет сквозь пространство, открывающий кадр.
- **По умолчанию.** 50-60 км/ч (14-17 м/с), высота 1,9-5 м. Змейка `x = 1.4·sin(1.35t)`, крен `0.34·sin(1.35t + 0.5)`, рысканье `−0.16·cos(1.35t)`, нос вниз на 3-20°. Аллея деревьев по обе стороны пути на 4-7 м от оси, шаг 6-7 м. Для погони камера стартует сзади и сверху (10 м за героем, 5 м высоты), пикирует, проходит над ним и открывает цель впереди.
- **Код.** `rigs.fpv(cam, t)`. В погоне считай позицию относительно героя, например `cz = heroZ + lerp(10, -4, e)`, `cy = lerp(5.2, 1.9, e)`.
- **Ловушки.** Скорость читается только по близким предметам, в пустом поле FPV выглядит медленным. Убери со траектории все, во что камера влетит. Крен должен совпадать с направлением поворота, обратный крен выглядит как ошибка.

### 12 Голландский угол · dutch angle

- **Суть.** Камера заваливает горизонт вокруг оси объектива.
- **Когда.** Растерянность, тревога, мир сломался, злодей.
- **По умолчанию.** От 0 до 18-21° за 0,7-2 с. Показание «∠ 18°». Хорошо работает, когда герой при этом оглядывается.
- **Код.** `rigs.dutch(cam, k, { to: 18 })`, то есть `cam.rotation.z = rad(a)` при порядке `YXZ`. Если камера уже повернута через `lookAt`, добавь крен через `cam.rotateZ(rad(a))`.
- **Ловушки.** Меньше 10° выглядит как кривой штатив, больше 25° как переворот. Держи 15-21°.

### 13 Слоумо · slow motion

- **Суть.** Сюжетное время идет медленнее реального, обычно в 4 раза (120 к/с при показе на 30).
- **Когда.** Пик действия, красота момента, радость, полет.
- **По умолчанию.** Скорость ×0,25. Медленно плывущие частицы (конфетти, листья) лучше всего продают замедление, без них слоумо похоже на зависание. Показание «120 к/с ×0,25». Звук ниже и мягче, редкие удары сердца.
- **Код.** `const T = makeStoryTime(piecewiseRate([{ until: 1.4, rate: 1 }, { rate: 0.25 }]))`. Все движения сцены (и камеры, если это одна съемка) считаются от `T.story(u)`.
- **Ловушки.** Если частицы или камера остались в реальном времени, а герой замедлился, эффект разваливается. Для бесшовной петли делай циклы частиц кратными периоду петли.

### 14 Спидрамп · speed ramp

- **Суть.** Скорость меняется внутри одного кадра без склейки. Обычно быстро, потом резко медленно на пике действия, потом снова быстро.
- **Когда.** Прыжок, удар, рывок, акцент в спорте и экшене.
- **По умолчанию.** Скорость 1 до 1,3 с, спад до 0,2 к 1,7 с, держится 0,2 до 2,4 с. В демонстрации можно показать график скорости в углу кадра (линия и точка на текущем времени) и показание «×2,4» → «×0,3».
- **Код.**
  ```js
  const T = makeStoryTime(piecewiseRate([{ until: 1.3, rate: 1 }, { until: 1.7, to: 0.2 }, { until: 2.4, rate: 0.2 }, { rate: 1 }]));
  const apex = T.story(2.4);   // вершина прыжка попадает в медленный участок
  // взлет в apex − 0.28, приземление в apex + 0.28 сюжетного времени, препятствие под вершиной
  ```
- **Ловушки.** Медленный участок без события внутри бессмыслен, пик действия должен совпасть с минимумом скорости. Не подкладывай под график непрозрачную плашку, она закроет героя.

### 15 Таймлапс · time-lapse

- **Суть.** Часы сжаты в секунды. Солнце идет по дуге, облака несутся, прохожие мелькают, небо меняет цвет.
- **Когда.** Прошло много времени, ожидание, день сменяется вечером.
- **По умолчанию.** 06:00 → 18:00 или 12:00 → 19:00 за 1,8-4,2 с, часы с шагом 10 минут. Солнце по дуге с азимутом от −55° до +55° и высотой `3 + 30·sin(πf)` градусов. Облака на 230 м летят со скоростью 85-160 м/с. Прохожие как тонкие капсулы на 5-14 м от камеры, их позиции меняются ступенькой каждые 0,1-0,12 с от сида `rng(floor(t / 0.1)·31 + i·7)`. Небо и туман плавно уходят в теплый вечерний цвет. Неподвижный герой на фоне несущегося мира усиливает прием.
- **Ловушки.** Плавно идущие прохожие выглядят как обычная съемка, нужна ступенька. Прохожие близко к камере превращаются в столбы.

### 16 Стоп-кадр · freeze frame

- **Суть.** Время останавливается на одном кадре, потом снова идет.
- **Когда.** Вот этот момент, комедийная пауза, вершина прыжка, знакомство с героем.
- **По умолчанию.** Остановка 0,9-1,8 с ровно в вершине действия. Рамка акцентным цветом по краю кадра, знак паузы из двух полос внизу по центру, показание «СТОП-КАДР». Звук обрывается, остается высокий звон (около 1760 Гц), выход из паузы со свистом.
- **Код.** Участок `{ until: b, rate: 0 }` в графике скорости или явно `m = t < a ? t : t < b ? a : t − (b − a)`.
- **Ловушки.** Если передний план или частицы двигаются во время паузы, это уже не стоп-кадр, поэтому все берет время из `story`. Проверь кадр паузы отдельно, в нем чаще всего что-то закрывает героя.

## Переходы (17-24)

Переход соединяет две сцены A и Б. У каждой сцены свой `setup`, а компоновщик рисует одну, другую или обе сразу с прозрачностью, обрезкой или смазом. Звуковые склейки (J и L) живут в звуковой дорожке, картинка в них режется жестко.

Для демонстрации перехода удобен период 9,4 с. Первая половина A → Б, вторая Б → A, тогда петля замыкается без растворения. Показание «А → Б» и «Б → А».

### 17 Джамп-кат · jump cut

- **Суть.** Тот же план с той же точки, но время прыгает вперед. Герой в другом месте или в другой позе, часы показывают другое время.
- **Когда.** Скука, ожидание, рваный ритм.
- **По умолчанию.** 4 состояния по 0,45 с в динамичном ролике или по 1,2 с в демонстрации. Без твина, жесткая смена. Позы стоит, лежит, руки вверх, стоит в другом месте. Часы «10:02» → «10:47» → «11:36» → «12:20». Щелчок на каждой смене.
- **Код.** `const st = STATES[jumpIndex(u, 4, 0.45)]`.
- **Ловушки.** Камера не двигается совсем, иначе это обычная склейка. Состояния должны заметно отличаться положением, иначе скачок выглядит как сбой рендера.

### 18 Матч-кат · match cut

- **Суть.** Склейка двух разных сцен по совпадению формы, цвета, движения или положения в кадре. Подброшенный мяч становится солнцем.
- **Когда.** Рифма, перенос во времени или пространстве одним жестом, смысловой финал.
- **По умолчанию.** План 1 длится около 1 с. Герой бросает, мяч летит из точки руки в точку `(0.70·W, 0.20·H)`, растет от 9 до 46 px (на ширине 1920), путь дугой вверх, `easeOut`. Жесткая склейка. План 2 длится около 0,9 с, это пейзаж без героя, и солнце той же формы, размера и цвета стоит в той же точке. На склейке колокол.
- **Код.** Позицию руки возьми из проектора `p(x, y, z)`, который возвращает проход плана 1. Мяч и солнце рисуй 2D-кругом в одних и тех же координатах, так совпадение будет точным.
- **Ловушки.** Если объект на склейке сдвинулся хоть на несколько пикселей или сменил цвет, глаз видит две разные вещи. Если в сцене есть 3D-солнце, отключи его в обоих планах.

### 19 Панорама-переброска · whip pan

- **Суть.** Камера поворачивается так быстро, что кадр смазывается в полосы. Внутри смаза прячется склейка в другое место, или камера честно переводится на другой объект той же сцены.
- **Когда.** Энергичный переход, связь двух мест, «тем временем», комедия.
- **По умолчанию.** Пауза 0,2 с, увод A на 35-45° за 0,3 с с ускорением, приход Б с той же стороны за 0,3 с с замедлением. Смаз пропорционален угловой скорости, максимум примерно 8% ширины кадра. Свист шумом, полоса частот едет вверх.
- **Код.**
  ```js
  const w = whip(u, { start: 0.2, dur: 0.6, angle: 40, blur: 150 });
  C.shot((cam) => { (w.side === 'from' ? setupA : setupB)(cam); cam.rotation.y = rad(w.yaw); }, { hblur: w.hblur });
  ```
  Внутри одной сцены (с героя на машину) поверни камеру на реальный угол до объекта `−atan2(objX, camZ − objZ)`, а смаз задай как `blur·sin(π·прогресс)`.
- **Ловушки.** Слишком большой угол уводит камеру в пустоту, и смаз становится белым пятном. Направление увода и прихода должно быть одним, иначе склейка видна.

### 20 Наплыв · cross dissolve

- **Суть.** Один план становится прозрачным, второй проявляется. Какое-то время видны оба.
- **Когда.** Мягкая смена места или времени, воспоминание, финальная плашка.
- **По умолчанию.** 0,8-1,2 с, ease in-out. Для финала сцена продолжает двигаться, а поверх с прозрачностью `k` проявляется финальная плашка. Рамка и показания камеры при этом гаснут как `1 − k`.
- **Код.** `C.shot(setupA); if (k > 0) C.shot(setupB, { alpha: k })` при `k = dissolve(u)`.
- **Ловушки.** Медленные растворения в динамичном ролике тянут темп. Для динамики режь жестко, наплыв оставь на смену времени и финал.

### 21 Шторка · wipe

- **Суть.** Граница едет по кадру и открывает второй план. Еще его называют вытеснением.
- **Когда.** Смена главы, игривый переход, сравнение «было и стало».
- **По умолчанию.** Вертикальная граница слева направо за 1,1 с, ease in-out. Тонкая акцентная линия на границе.
- **Код.** `C.shot(setupA); C.shot(setupB, { clip: { x: 0, y: 0, w: lx, h: H } })` при `lx = wipeX(u, W)`. Затем линия `ctx.fillRect(lx − 1, 0, 2, H)`.
- **Ловушки.** Направление шторки одно на весь ролик. Без линии граница теряется на похожих фонах.

### 22 Смэш-кат · smash cut

- **Суть.** Резкий обрыв со спокойной сцены на контрастную, без перехода. Контраст во всем сразу. Общий план против крупного, статика против тряски, тишина против удара.
- **Когда.** Шок, шутка, пробуждение, хук в первую секунду.
- **По умолчанию.** Тихая часть. Общий план, герой лежит, буквы «z» поднимаются и тают, тихий гул, показание «♪ тихо», индикатор громкости с одним делением. Громкая часть. Камера низко и близко `(0.25, 0.72, 2.5)` смотрит вверх на `(0, 1.3, 0)`, крен −7°, 20 мм. Руки вверх, тряска от сида, 18-22 акцентных луча от головы, перерисовка 12 раз в секунду. Индикатор громкости полный, показание «♪ ГРОМКО». Звук бьет ровно в кадр склейки.
- **Код.** Две функции кадра и жесткое `if (u < cut)`. Лучи считаются от проекции головы `p(0, 1.45, 0)`.
- **Ловушки.** Если звук опережает или опаздывает хотя бы на кадр, удара нет. Тихая часть должна быть по-настоящему тихой, иначе контраста нет.

### 23 J-склейка · J-cut

- **Суть.** Звук следующей сцены начинается раньше, чем склеивается картинка. Зритель еще видит A, но уже слышит Б.
- **Когда.** Звук зовет в следующую сцену, мягкая связка диалогов, интрига «что это за звук».
- **По умолчанию.** Опережение 0,3-0,5 с. Например, гудок машины звучит за 0,45 с до кадра, в котором машина появляется. Для демонстрации внизу кадра можно нарисовать таймлайн из двух дорожек «видео» и «звук». Склейка звука стоит раньше склейки видео, между ними подсвеченная зона и пунктир, плейхед едет слева направо, плашка «♪ звук А» становится «♪ звук Б» раньше, чем меняется картинка.
- **Код.** В звуковой дорожке звук Б начинается в `jCut(cutTime, 0.45).audioStart`, картинка режется ровно в `cutTime`.
- **Ловушки.** Опережение длиннее секунды читается как ошибка синхрона. Звук Б должен быть узнаваемым, иначе зритель не свяжет его со следующим кадром.

### 24 L-склейка · L-cut

- **Суть.** Картинка уже сменилась, а звук прошлой сцены еще тянется и затихает.
- **Когда.** Эмоция не отпускает, реплика договаривается за кадром, будильник звенит и в следующей сцене.
- **По умолчанию.** Хвост 0,3-1,5 с с затуханием в последние 0,5 с.
- **Код.** Звук A заканчивается в `lCut(cutTime, 0.4).audioEnd`, громкость `1 − smooth(end − 0.5, end, t)`.
- **Ловушки.** Без затухания хвост обрывается щелчком. Громкий хвост поверх громкого начала Б превращается в кашу.

## Звук приемов

Звук делает половину работы приема. Его можно синтезировать кодом (Web Audio в браузере или офлайн-синтез в Node с записью WAV) и привязать события к тем же временам, что и кадры. Храни таймлайн в одном модуле, который читают и картинка, и звук, тогда сдвиг кадра сдвигает и звук.

| Прием | Звук |
|---|---|
| смэш-кат | удар и короткий свист ровно в кадр склейки |
| долли-зум | тон вверх (примерно 110 → 520 Гц), нарастающий шум |
| панорама-переброска | свист шумом, полоса частот едет вверх |
| спидрамп | «пленка тормозит» (тон вниз 260 → 45 Гц), сердцебиение в медленном участке |
| стоп-кадр | тишина и высокий звон, выход свистом |
| FPV-дрон | жужжание пилообразной волной около 185 Гц с вибрато, свисты предметов мимо |
| джамп-кат | щелчок или тик часов на каждой смене |
| таймлапс | тиканье ускоряется, арпеджио вверх |
| матч-кат | колокол или мягкий удар на склейке |
| J- и L-склейки | звук Б раньше картинки, звук A после склейки с затуханием |

Шаги и удары считай от сюжетного времени (`T.real(s)` дает реальное время события), тогда в слоумо они редеют, а в стоп-кадре пропадают. Перед публикацией сведи громкость примерно к −14 LUFS.

## Подписи и показания камеры

Если ролик учит приемам, подписывай их прямо в кадре.

- **Плашка приема** внизу слева на время приема. Номер акцентным цветом, русское название крупно, английский термин мельче и серым. Въезд за 0,28 с, уход за 0,16 с. На кадре 1920×1080 номер и название около 54 px, термин около 38 px, высота плашки около 98 px. Мельче на телефоне не читается, проверяй кадр уменьшением до 390 px по ширине.
- **Показание камеры** справа вверху моноширинным шрифтом. Фокусное, скорость, угол, высота, часы, «СТОП-КАДР». Слева вверху мигающая точка «REC», по углам уголки видоискателя. Нужны глифы ♪, ∠, ◎, ↑, поэтому выбирай шрифт, где они есть.

## Рендер и проверка

- Собери страницу, которая отдает `window.renderFrame(t)` и `window.grab()` (снимок холста). Открой ее в headless-браузере (например Puppeteer) по http, а не с `file://`, иначе текстуры WebGL могут не загрузиться. Для каждого кадра вызови `renderFrame(i / fps)`, сними JPEG и передай по трубе в ffmpeg (`-f image2pipe -c:v mjpeg`, затем H.264, yuv420p).
- Шрифты подключи заранее и дождись `document.fonts.load(...)` до первого кадра, иначе первые кадры отрисуются запасным шрифтом.
- Для мелкого кадра (меньше 600 px по ширине) рендери сцену в 2 раза больше и уменьшай при отрисовке, иначе тонкие линии и грани рвутся. Для 1920×1080 хватает встроенного сглаживания.
- Проверка до полного рендера. Стоп-кадры в ключевых точках каждого приема и лист кадров раз в 0,5 с по всему ролику (`ffmpeg -vf "fps=2,scale=384:-1,tile=6x10"`). После рендера проверь длительность, число кадров и громкость, а ролик целиком со звуком нужно посмотреть человеку.

## Общие ловушки

- Плоский персонаж сбоку превращается в палку. Позы с поднятыми руками показывай спереди или под углом до 50°.
- Предметы переднего плана (столбы, ветки) закрывают героя именно в стоп-кадре или в вершине движения. Проверяй ключевой кадр отдельно и сдвигай предметы.
- Объект за героем на одной линии с камерой слипается с ним в один силуэт. Проверяй линию «камера, герой, фон» на всех углах облета и панорамы.
- Все, что включает какой-то кадр, должно выключаться в общем `reset()`, иначе объекты протекают в соседние кадры.
- Прием, который нельзя увидеть без пояснения, не работает. Сначала построй сцену, которая делает его видимым.
- Обычное движение без мотивации превращает ролик в скринсейвер, а новая карточка на каждый бит превращает его в слайдшоу. У каждого движения должна быть причина в истории.

## Приемы в промптах для видеомоделей

Видеомодели (Veo, Kling, Sora, Runway и похожие) понимают английские операторские термины гораздо лучше, чем «сделай кинематографично». Формула такая. Сначала термин, потом объект, направление и скорость или длительность. Например «slow dolly in toward the subject over 3 seconds». Один прием на шот, два движения в одном промпте модели часто смешивают.

| № | Прием | Строка для промпта |
|---|---|---|
| 01 | Панорама | slow pan from left to right across the street |
| 02 | Вертикальная панорама | tilt up from the character to the top of the tower |
| 03 | Наезд | slow dolly in toward the subject over 3 seconds |
| 04 | Зум | quick crash zoom in on the character's face |
| 05 | Проводка | tracking shot moving alongside the running character |
| 06 | Облет | 180-degree orbit around the character, camera at chest height |
| 07 | Кран вверх | crane up and away, revealing the empty square |
| 08 | Долли-зум | dolly zoom, subject stays the same size while the background stretches |
| 09 | Перевод фокуса | rack focus from the flower in the foreground to the person in the background |
| 10 | Ручная камера | handheld camera with subtle natural shake |
| 11 | FPV-дрон | fast FPV drone shot flying low between the trees, banking into turns |
| 12 | Голландский угол | dutch angle, horizon tilted 20 degrees |
| 13 | Слоумо | slow motion, confetti floating in the air |
| 14 | Спидрамп | speed ramp, real-time run slowing into slow motion at the peak of the jump |
| 15 | Таймлапс | time-lapse from noon to sunset, clouds racing, crowds flickering |
| 16 | Стоп-кадр | freeze frame at the top of the jump |
| 17 | Джамп-кат | jump cuts in the same framing, the character in different poses as time passes |
| 18 | Матч-кат | match cut from the thrown ball to the sun in the same position |
| 19 | Панорама-переброска | whip pan to the car with motion blur |
| 20 | Наплыв | cross dissolve to the evening scene |
| 21 | Шторка | wipe transition from left to right |
| 22 | Смэш-кат | smash cut from a quiet bedroom to a loud alarm close-up |
| 23 | J-склейка | J-cut, the car horn is heard before we see the car |
| 24 | L-склейка | L-cut, the alarm keeps ringing over the next shot |

Склейки (17-24) внутри одного сгенерированного клипа модели делают нестабильно. Надежнее сгенерировать два шота и склеить их в монтаже, а термин использовать для описания замысла.
