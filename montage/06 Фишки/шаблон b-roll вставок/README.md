# Шаблон: говорящая голова + вставки записи экрана

1. Видео с телефона положи в `inbox/`. Дубли идут по порядку имён: 01, 02 и дальше.
2. Записи экрана положи в `broll/` и пропиши их в `BROLL_SPECS` в `build.py`: файл, куски, кроп.
3. В `config.json` задай заголовок, CTA, слова-триггеры вставок и правки расшифровки.
4. Запусти `python3 scripts/build.py`. Готовый ролик — `edit/out/reel.mp4`.

Что делает сам:
- расшифровка через faster-whisper;
- резка только пауз длиннее 0,5 с;
- караоке-субтитры;
- шапка с заголовком на хуке и CTA в конце;
- вставка записи экрана, когда в речи звучит слово-триггер. Пока говоришь о вставке, она идёт; если говоришь коротко, ускоряется до x2.

Только план без рендера: `python3 scripts/build.py --plan`.
Подвинуть вставку руками: правь `edit/plan.json`, поставь `"manual": true`, запусти снова.

Переменные окружения: `VENV_PY` — python с faster-whisper, `NODE_PROJECT` — папка с установленным playwright-core для `title.mjs`.
