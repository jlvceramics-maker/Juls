# Монтажерский пак

Набор для вертикальных роликов 1080×1920 (Reels, Shorts, TikTok): фоны, субтитры, заголовки, шрифты, звуки, правила монтажа и пара приёмов. Визуальная витрина — `index.html`, открывается в браузере.

## Что брать под задачу

| Ролик | Что брать |
|---|---|
| Говорящая голова с телефона | `02 Субтитры/build.py` + `03 Заголовки и плашки/title.mjs` + правила монтажа ниже |
| Говорящая голова + вставки записи экрана | `06 Фишки/шаблон b-roll вставок/` |
| Подложка под b-roll, запись экрана, графику | фоны из `01 Фоны/` |
| Моушн-ролик без лица | фон из `01`, палитра и кривые движения ниже, звуки из `05` |

## Что нужно установить

- ffmpeg.
- Python 3 с `faster-whisper` для расшифровки.
- Node.js с `playwright-core` и Chrome для заголовков и генератора фонов: `npm i playwright-core` в любой папке, скрипты запускать оттуда.

## 01 Фоны

8 бесшовных лупов: 1080×1920, 20 с, 30 fps, без звука. Сгенерированы шейдером. Превью всех — `все-фоны.jpg` (верх dark, низ light).

| Стиль | dark | light |
|---|---|---|
| blueprint — миллиметровка с лёгкой волной | тёмно-синий | бело-голубой |
| contour — изолинии, как топокарта | шоколад | бежевый |
| diagonal — косая сетка | графит | светло-лаймовый |
| dots — точки | тёплый градиент | бумага |

Генератор новых фонов — `генератор bg-lab/`:
- `node render.mjs <style> <dark|light> out.mp4` — один фон, около 4 минут.
- `node batch.mjs` — все восемь в папку `out/`.
- `node checkloop.mjs <style>:<palette>` — проверка стыка лупа, норма от 60 дБ.
- Цвета правятся в `palettes.js`, рисунок — в `shaders.js`.

Правило генератора: множитель фазы `uPhase` только целый, иначе луп рвётся на стыке.

## 02 Субтитры

Караоке: `build.py` + `ReelSub.ttf` + `transcribe.py` (faster-whisper large-v3).

- Шрифт ReelSub (статичный Inter Tight 900), 78 px, капс, белый.
- Обводка чёрная 5 px, тень 2.
- Произносимое слово подсвечивается #FFF4A3, только цветом, без увеличения.
- До 3 слов и 17 знаков в строке. Висящих одиночных слов нет, связки вроде «Claude Code» не рвутся (`KEEP_TOGETHER`).
- Низ кадра, MarginV 260 — это y около 1660 из 1920, выше интерфейса Instagram.

Структура папки ролика:

```
reel/
  inbox/IMG_0001.MOV      исходники с телефона
  edit/fonts/ReelSub.ttf  шрифт субтитров
  scripts/build.py
  scripts/title.mjs
```

В `build.py` заполни `REELS` (какие клипы в каком порядке) и `TITLES` (заголовок), потом `python3 scripts/build.py`. Готовое — в `edit/out/`.

Whisper путает названия: «клад» вместо «Claude», «броунд» вместо «промпт». Правки — в списке замен в `build.py`, остальное руками.

## 03 Заголовки и плашки

| Скрипт | Что рисует |
|---|---|
| `title.mjs` | белые скруглённые плитки-иконки через «+», под ними заголовок в две строки Inter Tight 900, слово в [скобках] лаймом #C8F04C |
| `title2.mjs` | маленькая строка-подводка сверху и крупный белый заголовок одной строкой, без иконок |
| `title3.mjs` | ранняя версия `title.mjs` с иконкой сервера |
| `badge.mjs` | белый круг со знаком Claude, поп-ин над заголовком |
| `title-card.mjs` | заголовок поверх готового ролика, слово в [скобках] рукописным шрифтом лаймом |
| `card.mjs` | белая карточка со скриншотами и лаймовыми выделениями для пруф-вставки |

Правила заголовка:
- Стоит на y около 250, не ниже y 500, иначе заденет лицо.
- Появляется на кадре 0, гаснет к концу хука.
- Без затемнения и плашек, только мягкая тень.

## 04 Шрифты

- `ReelSub.ttf` — субтитры.
- `InterTight[wght].ttf` — заголовки, вес 900.
- `Onest[wght].ttf` — текст в моушн-графике.
- `JetBrainsMono[wght].ttf` — терминал и код.
- Unbounded, Caveat, Tektur, Comfortaa, Pacifico, Bad Script, Marck Script, Montserrat Alternates — акценты.

`title-card.mjs` по умолчанию берёт Unbounded и Caveat из `04 Шрифты/`. Другой шрифт — флагами `--font` и `--hand`.

## 05 Звуки

- `синтез/` — pop, tick, shine, boom, whoosh, key, typing. Сгенерированы ffmpeg.

Звук ставится на событие: появился объект — pop, выросло число — tick, вывод — shine, удар — boom, переход — whoosh.

## 06 Фишки

- `dolly-zoom/` — фейковый dolly zoom: маска человека через Apple Vision (`personmask.swift`, только macOS), фон уезжает, лицо стоит на месте (`dollyzoom.py`).
- `шаблон b-roll вставок/` — говорящая голова, в которую по словам-триггерам из речи встают записи экрана. Вставка ускоряется до x2, если о ней говорят коротко. Инструкция внутри.
- `camera-moves/` — 24 приёма камеры и монтажа для роликов кодом и готовые английские строки для промптов Veo, Kling, Sora. `camera-kit.js` — риги камеры и переходы.

## Движение

- Появление слова: блюр 14 px, подъём 40 px, 16 кадров, cubic-bezier(0.16, 1, 0.3, 1).
- Кривые: OUT (0.16, 1, 0.3, 1), IN (0.7, 0, 0.84, 0), INOUT (0.65, 0, 0.35, 1). 30 fps.
- Смена сцены без перекрытия: два заголовка в блюре одновременно — брак.
- Сетка фона одна на весь ролик.
- Хук на кадре 0: крупный текст уже на экране. Пустой старт с влётом по одному слову теряет зрителя.

## Монтаж говорящей головы

- Резать только паузы от 0.5 с и не в ноль: оставлять около 0.35 с (0.2 после слова, 0.15 до следующего). silencedetect -35 dB.
- Нет длинных пауз — не резать ничего. На ролик выходит 1–4 склейки, а не 10. Плотная резка съедает окончания слов.
- Без цветкора и виньетки, картинка как из камеры.
- Громкость: loudnorm I=-14, TP=-1.5. Вставки с телефона звучат около -27 LUFS, их выравнивать.
- Перед concat ставить `setsar=1`, иначе склейка падает после кропа 9:16.
- Экспорт: мастер crf 16, отправка crf 23. Битрейт 2400k держит 90 с под 30 МБ.
- Запись экрана в Chrome: при смене контента страница держит прокрутку, нужен `overflow-anchor:none` и сброс `scrollTop`.
- Проверка до отправки: лист кадров из mp4 и пара кадров в полном разрешении.
