# Промт для монтажа роликов «Ретрограда»

Скопируйте всё, что ниже линии, в начало нового чата (или попросите Claude в этом репозитории прочитать `retrograd/montage-prompt.md`).
Промт собран по правкам, сделанным при монтаже вступления (история изменений `retrograd/video/` в git). Если какие-то правки по другим роликам здесь не учтены — допишите их в раздел «Правки автора».

---

## Задача

Ты монтируешь вертикальные ролики (рилсы) для блога «Ретроград» композитора Михаила Смирнова: говорящая голова + субтитры + фото-вставки.
Площадки: Instagram Reels, VK Клипы, YouTube Shorts, TikTok, Telegram. Стиль — спокойный, интеллигентный, «тёплый ретро»: без кислотных эффектов и суеты.

Перед работой прочитай:
- `retrograd/CLAUDE.md` — правила проекта и обязательная проверка видео;
- `montage/CLAUDE.md` и `montage/README.md` — монтажный пак (субтитры, плашки, фоны);
- `retrograd/video/render_cut.py` — сборка финального вступления, это **эталон** монтажа: бери его за основу.

## Исходники

- Автор снимает ролик **частями** (блоками по 10–20 секунд, каждый файл меньше 30 МБ).
- Части могут **перекрываться**: следующий кусок начинается с кадров, которые уже были в конце предыдущего. Перед склейкой найди перекрытие покадровым сравнением стыков и обрежь начало следующей части (во вступлении обрезали 2, 5, 2, 6 и 15 кадров).
- Части склеивай через фильтр `concat` (а не через concat-демуксер) — иначе на стыках бывают сбои.
- Если исходник низкого качества — повышение резкости/разрешения (`video/render_sr.py`).
- Текст ролика у автора есть заранее (`retrograd/reels-week-*.md`, `prompt.md`) — используй его для сверки субтитров.

## Формат на выходе

- 1080×1920, 30 кадров/с, H.264 (crf 18), цвет **bt709** (при декодировании и кодировании явно указывать матрицу bt709 — иначе цвета «плывут»), звук AAC 256 кбит/с, `+faststart`.
- Длина звука равна длине видео.
- Готовый mp4 отправляем автору файлом. `*.mp4` в git не коммитим.

## Монтаж: склейки и планы

- **Стиль рилс:** вырезаем паузы между фразами, оставляя короткий воздух (во вступлении оставляли 0,2–0,25 с). Монтажный пак рекомендует резать паузы только от 0,5 с — короче не трогать.
- **Склейки — точно по кадрам**, по середине паузы.
- **На каждой склейке меняется план** (крупность): общий 1.0 → чуть ближе 1.12 → 1.2 → снова общий… Чередовать, чтобы картинка «дышала». Центр кадра — лицо автора.
- **Одна ключевая фраза ролика — крупным планом** (во вступлении — «…возможность любить»). Вокруг кульминации — спокойнее, без частых смен.
- **Никаких «наездов» камеры (punch-in зумов)** внутри куска: ни плавных, ни мгновенных, ни с возвратом. Пробовали все варианты — автор их убрал. Крупность меняется **только на склейке**.
- Без цветокоррекции и виньетки.

## Субтитры

- Распознавание речи — Whisper, затем **обязательная ручная сверка с текстом автора**: Whisper путает слова («парельцам» вместо «по рельсам», «сладче» вместо «слаще», «иностранная» вместо «индустриальная»). Ни одной ошибки в субтитрах.
- Строка — **до 3 слов** (примерно до 15–20 символов). Перенос — на знаках препинания и паузах длиннее 0,35 с.
- **Предлог или союз не оставлять в конце строки** — переносить в следующую.
- ЗАГЛАВНЫМИ буквами, шрифт Inter Display Bold.
- Плашка: **тёмно-коричневая** (RGB 59, 36, 23), скруглённая, с мягкой тенью; текст белый, **ключевые слова — золотым** (RGB 244, 197, 110). Ключевые слова выбирать по смыслу ролика (во вступлении: КОМФОРТ, ИДОЛУ, СИМВОЛИЧНО, РОБОТА, ЛЮБИТЬ, УТЕШИТЕЛЬ, СВЯТОЙ ДУХ).
- **Размер небольшой** (48 px при ширине 1080), как в референсном рилсе: крупные субтитры автор уменьшал.
- Появление — быстрое лёгкое «выпрыгивание» (около 0,1 с).
- Положение — примерно на 68% высоты кадра, не закрывая лицо. **Когда на экране фото, субтитры опускаются ниже, под фото.**

## Фото-вставки

- Фото иллюстрируют ключевые слова (во вступлении: Святой Дух — икона Пятидесятницы; первый поезд).
- **Без рамок, без скруглённых углов, без тени** — чистая картинка (рамки и тени автор убрал).
- Появляются быстро, с лёгким «выпрыгиванием» и **звуком щелчка мыши** (`video/mouse_click.wav`).
- **Исчезают ровно на монтажной склейке** — не раньше и не позже.
- Пока на экране фото, **план не зумируется** — общий план.
- Чужие записи (музыка, видео из фильмов, фонограммы) не используем — только фото.

## Звук

- На каждом стыке — микро-фейды 10–12 мс, чтобы не было щелчков.
- Без перегруза (клиппинга). Задуманные звуки (щелчок на фото) — не ошибка.

## Проверка перед отправкой (обязательно)

`python3 retrograd/video/qa.py <видео> "<времена склеек через запятую>" "<времена появления фото>"`

Проверяет: 1080×1920 и bt709; длина звука = длине видео; нет застывших (повторяющихся) кадров; **на каждой склейке ровно один резкий кадр** (иначе «дёргается»); нет щелчков звука на стыках; фото исчезают на склейке.
Плюс посмотреть глазами кадры вокруг каждой склейки и лист кадров:
`ffmpeg -i out.mp4 -vf "fps=1,scale=270:-1,tile=6x4" sheet.png`.
Отправлять только при чистом результате.

## Описание к ролику

Вместе с видео готовить подпись для площадок по образцу `retrograd/video/intro-description.md`: короткий текст с хуком, 1–2 смайла, вопрос для комментариев, призыв подписаться, девиз «Ретроград не идёт назад — он просто не бежит», 8–10 хэштегов (#ретроград #композитор …). Для YouTube/Telegram/VK — длинная версия.

## Правки автора (история)

1. Цветовая матрица и стыки частей — исправлены (bt709, фильтр concat).
2. Перекрывающиеся кадры на стыках частей — обрезаны.
3. Рамки вокруг фото — убраны.
4. Плавные наезды камеры → мгновенные → с возвратом на следующей фразе → **убраны совсем**.
5. Вместо наездов — монтаж в стиле рилс: вырезанные паузы, смена плана на склейках, фото со щелчком.
6. Щелчок — звук мыши; на фото без зума; субтитры под фото ниже.
7. Склейки и смена планов — точно по кадрам; вокруг кульминации — спокойнее.
8. Фото исчезают ровно на склейке; добавлена обязательная проверка `qa.py`.
9. Субтитры уменьшены под размер референсного рилса.
