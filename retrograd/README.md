# Ретроград

Рабочие материалы для видеоблога «Ретроград» — блога музыканта и композитора о том, что прогресс забрал у нас незаметно.

## С чего начать
1. `concept.md` — концепция, тон, формулы хуков, шаблон ролика.
2. `topics/` — первые три ролика, расписанные по структуре:
   - `01-composer-vs-ai.md` — «Композитор против нейросети» (эксперимент, слепой тест)
   - `02-oscar.md` — «Когда умер Оскар»
   - `03-letter.md` — «Письмо, которое переживёт вас»
3. `interview.md` — вопросы автору (не обязательно для старта, но усиливает ролики).
4. `backlog.md` — банк следующих тем с хуками.

`CLAUDE.md` — контекст проекта для Claude: открывайте этот репозиторий в новой сессии, и Claude сразу поймёт, о чём речь.
